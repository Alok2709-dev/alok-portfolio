# ALOK.OS

A static personal developer portfolio built with HTML, CSS, and vanilla JavaScript. It works on GitHub Pages, Vercel, or any static host.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Personal placeholders to replace

- Per-project `github` and `live` URLs in the `projects` array in `script.js`
- Project years/statuses, descriptions, screenshots and developer log entries in `script.js` as your work develops

## Notes

- Project content is defined at the top of `script.js`.
- The boot sequence stores a session flag; clear session storage to see it again.
- `prefers-reduced-motion` disables the decorative animations.
- Terminal commands are safe, predefined responses only.
